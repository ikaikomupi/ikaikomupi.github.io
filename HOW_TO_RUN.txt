AIKU WEBSITE - HOW TO RUN
=========================

REQUIREMENTS
------------
- Node.js v18 or higher
- npm (comes with Node.js)


NAVIGATE TO PROJECT FOLDER
---------------------------
  cd "/Users/rafi/Documents/AIKU Website"


INSTALL DEPENDENCIES (first time only)
---------------------------------------
  npm install


DEVELOPMENT (local)
--------------------
  npm run dev

  Opens at: http://localhost:5173
  Hot reload is enabled — changes reflect instantly in the browser.


BUILD FOR PRODUCTION
---------------------
  npm run build

  Output goes to the /dist folder.


PREVIEW PRODUCTION BUILD LOCALLY
----------------------------------
  npm run preview

  Opens at: http://localhost:4173


DEPLOY (GitHub Pages)
---------------------
  Otomatis lewat .github/workflows/deploy.yml setiap push ke branch main.

  Website utama: https://ikaikomupi.github.io  (remote "org")
    git push org main
    git push origin main   (repo pribadi, cadangan)


CATATAN PENTING (perlu tindakan di Google Apps Script)
------------------------------------------------------
  docs/keamanan-admin.md  - pasang ADMIN_KEY supaya hanya pengurus bisa tambah event/artikel
  docs/foto-upload.md     - aktifkan upload foto di form Daftar
  docs/cpns-data.md       - format data & form Lapor Hasil KOMpas ASN
  src/lib/analytics.js    - isi GOATCOUNTER_CODE untuk mengaktifkan statistik pengunjung

PROJECT STRUCTURE
------------------
  src/
    components/
      LandingPage.jsx     - Homepage
      Navbar.jsx          - Navigation bar
      Directory.jsx       - Alumni directory
      ProfilePage.jsx     - Individual alumni profile
      RegisterForm.jsx    - Registration form
      OrgPage.jsx         - Organization page
      CecepPage.jsx       - Candidacy page (Calon Ketua AIKU)
    data/
      alumni.js           - Alumni data
    lib/
      sheets.js           - Google Sheets integration
      form.js             - Form utilities
    App.jsx               - Routes configuration
    main.jsx              - Entry point
    index.css             - Global styles (Tailwind)
  public/                 - Static assets (images, etc.)
  dist/                   - Production build output (git-ignored)


ROUTES
-------
  /                  - Homepage
  /directory         - Alumni directory
  /organisasi        - Organization info
  /calon-ketua       - Cecep's candidacy page
  /register          - Register form
  /cpns              - KOMpas ASN: ringkasan formasi CPNS (prototipe)
  /cpns/rekomendasi  - Rekomendasi formasi dari skor tryout
  /cpns/lapor        - Form lapor hasil seleksi alumni
  /cpns/skb          - Persiapan SKB
  /cpns/metodologi   - Definisi, cara hitung, sumber data

  Update data CPNS: lihat docs/cpns-data.md, lalu jalankan npm run cpns:cek
  /profile/:id       - Alumni profile
